# FINN architecture and integrity — release handoff

Plain HTML/CSS/JavaScript, served with FastAPI from the same origin, preserves the existing mobile UI. SQLite holds append-preserving imported filings, private cached answers, session signer, aggregate usage/client limits and concurrency leases. Static versioned JSON provides public price and reviewed financial fixtures; restart loads changes.

Push: public Yahoo raw EOD bars + official exchange metadata → typed validation → deterministic anomaly baseline / keyword category / exact-attachment grouping → dated digest, company filters and configurable alerts. Latest import is pinned to a real stored timestamp; current-clock windows remain available. April/custom historical views hide later EOD/current-alert cards. Imported EOD is not live or intraday. Filings retain raw links and revised/effective dates when proven.

Pull: validated ticker/question → local typed plan → exact fiscal period, basis and known publication cutoff → verified FinancialFact / SourceEvidence → Decimal arithmetic, comparison and supported ratio OR bounded reasoning provider → structured citation/numeric validation → signed-session cache. Unknown tickers/periods return missing evidence. No model executes database queries, code or tools. Numeric comparisons preserve metric definition, currency, units, accounting standard and discrete quarter/annual periods.

Corpus: 18 mock holdings, authentic price series for 17 (1,071 bars), 432 filings, 11 financial research issuers, 16 source evidence records, 71 facts, two guidance records. Most new financial coverage is FY25/FY24 annual; Infosys and POWERGRID also have quarter comparisons. INFY notes are legacy curated; ten issuers use reviewed PDF extraction with hashes/pages. The model is not the financial database. Bank EBITDA and unverified metrics remain unavailable. Unknown publication dates are excluded at historical publication cutoffs.

Provider abstraction offers disabled, explicit mock and Google SDK providers. Real credential loading is lazy and runtime-only. SQLite BEGIN IMMEDIATE coordinates shared-file global/client counters and expiring leases. A bounded child process handles SDK deadline; defaults prevent unbounded retries/jobs. Production must be one host with durable storage, not independent replicas. Request-rate memory counters are not distributed. Signed cookies isolate cached responses, not authenticated user accounts.

Provenance and rights: selected derived financial facts and public filing metadata are included, with original publisher URLs, source/page/hash/extraction method and uncertainties. Full issuer PDFs, original assessment PDFs, private files and the old HDD corpus are not required or bundled. See PUBLIC_DATA_ACQUISITION.md, LIMITATIONS.md and CP09 for acquisition evidence/definitions. Rights are not globally certified; publisher access restrictions remain respected. No old project code, datasets, strategies or credentials were used.

Validation scope: local regressions, mock provider and responsive viewport checks. Public deployment, actual Gemini quality/quota/billing, physical devices and publisher rendering remain outside completed validation. See CP11_RELEASE_CHECKPOINT.md for final evidence and blockers.
