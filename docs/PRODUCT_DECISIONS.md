# Product decisions

P0: keep the Brief, source drill-down, configurable observations and narrow grounded research working locally. P1: show verified quarter comparisons and an honest initial-guidance example. P2 deferred: notifications, charts, embeddings, sector analytics and expanded evidence coverage.

The watchlist spans technology, banking, consumer, healthcare, industrials, automotive, materials, energy, utilities and telecom. It is an illustrative 18-label watchlist; current listing status and symbol transitions have not been comprehensively certified. Prices exist only for INFY, RELIANCE and HDFCBANK. Research candidates: Infosys first, TCS/HDFC Bank/Reliance/Sun Pharma for later primary-document acquisition. No financial coverage implied for candidates.

The shared evidence trail connects digest -> details -> research. Deterministic routing avoids runtime model costs. Unknown issuers receive coverage status rather than model-prior claims. Initial FY25 guidance comparison is explicitly narrower than a four-quarter promise history.

Use FastAPI with plain browser JavaScript instead of Next.js: no frontend build step and no third-party UI dependencies. This is a deliberate stack deviation, not a Next.js implementation. It leaves TypeScript/frontend automated test coverage for a later iteration.

Avoid trading, portfolio optimization and return predictions. Ranking is a category-relevance rule, not a materiality probability. Investor time is the scarce resource.
