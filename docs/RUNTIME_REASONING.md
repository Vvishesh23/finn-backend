# Bounded Gemini reasoning — optional backend integration

Credentials were explicitly deferred by the user. Defaults and placeholder values make no provider requests. `.env.example` is an example; export environment variables through a secure server configuration. Do not paste secrets into chat, put them in browser code, or commit `.env`.

After configuring a real backend secret and confirming account limits/billing, set AI_ENABLED=true and GEMINI_REASON_MODEL=gemini-2.5-flash. The model code/structured-output support were checked against official Google docs on 27 October 2026; no free quota is guaranteed. https://ai.google.dev/gemini-api/docs/models/gemini-2.5-flash and https://ai.google.dev/gemini-api/docs/pricing . Free-tier data treatment differs from paid services; use only approved public evidence and avoid personal information in questions.

Financial snapshot/guidance calculation routes are deterministic and never call the model. Interpretive retrieval calls the model at most once over bounded same-issuer reviewed evidence. Prompts contain no tools/search/URL-context facilities. Evidence is explicitly untrusted data. JSON claims must cite real selected evidence IDs; unsupported numeric tokens are rejected, never silently recalculated. These checks cannot establish semantic entailment: output remains MODEL_INTERPRETATION, with limitations and sources.

Default limits: 20 attempted calls/day; 50,000 conservative reserved tokens/day; 2 concurrent calls; 12,000 evidence characters; 800 output tokens; 20-second timeout. No automatic retries. SQLite daily reservations are atomic and retained after failures; provider-reported tokens recorded separately. Serialized UTF-8 byte reservation is conservative accounting, not a billing measurement. /api/usage reports aggregate counters without keys; money spent is not measured by this app. Identical concurrent queries share one computation; successful answers cache against source/fact/guidance/model/prompt versions. Provider errors return source-only fallback without a permanent error cache.

Use one worker. A persistent DB is required for durable daily limits. The supplied free Render blueprint keeps AI_DISABLED because its filesystem is ephemeral; do not enable paid inference there until budgets use durable storage and account-level spend limits are verified. Real API output quality, latency, token usage, free-tier entitlement and billing are UNVERIFIED. Tests use mocks; genuine issuer facts and synthetic provider responses are separate.
